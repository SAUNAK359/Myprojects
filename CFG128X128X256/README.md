# 🧠 TridentBrain V2
A hybrid **GNN + CNN + FFN** model designed for unified deep learning tasks including classification, regression, detection, and segmentation.  
Developed by **Saunak Das Chaudhuri**.

---

## 🔧 Features
- 🧩 Modular architecture — `encoders`, `fusion`, `heads`
- 🧠 Gaussian Process head for probabilistic uncertainty
- ⚙️ Auto dataset handling (MNIST + COCO-mini)
- 🧪 Full GitLab CI/CD automation (build → train → test → publish)
