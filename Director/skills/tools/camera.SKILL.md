Tool calls are proposals, not commands. The deterministic validator owns ranges, conflicts and capability checks. Use normalized focus coordinates only when confident about the intended subject. Exposure values are EV stops, not device indices. Torch affects continuous illumination; still_flash affects only still capture. OEM extensions may conflict with torch/flash and must only be requested when listed. Creative looks use optional strength 0..1 and never require a physical recapture by themselves.
